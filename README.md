# SanArt — запись на пробный урок

Сайт, на котором человек сам записывается на бесплатный пробный урок в музыкальную школу SanArt:
выбирает день, время и инструмент, оставляет имя и телефон, получает подтверждение в WhatsApp.
Все данные хранятся в CRM **МойКласс**: сайт ничего не хранит у себя, ссылки отмены подписаны секретом.
Работает на **Vercel** (бесплатный тариф Hobby), Node 18+, без npm-зависимостей.

## Правила

- **Инструменты** — группы МойКласс из `MOYKLASS_TRIAL_GROUPS` (сейчас: вокал, гитара, фортепиано).
  У каждого инструмента свой список кабинетов.
- **Свободное время.** Рабочий день 10:00–22:00, урок 45 мин, старты каждые 15 мин (10:00 … 21:15).
  Уроки идут параллельно в разных кабинетах: занятие занимает только свой кабинет, занятие без кабинета —
  все кабинеты. Время показывается, если для инструмента свободен хотя бы один его кабинет на все 45 минут.
- **Неделя.** Показываются 7 дней от сегодня. Если в них всё занято, сайт ищет первую неделю со свободным
  временем (до 8 недель вперёд) и пишет «Ближайшие дни заняты. Первое свободное время — …».
- **Записаться и отменить** можно не позже чем за 3 часа до урока. Позже отмена невозможна — пробный сгорает.
- **Одно пробное на номер телефона.** Отменённое вовремя возвращает право.
- **Запись** создаёт в МойКласс отдельное индивидуальное занятие «Пробный урок» на 45 минут
  в первом свободном кабинете инструмента, без преподавателя (его назначает администратор).
  Ученик перед этим записывается в группу инструмента.
- **Отмена** удаляет это занятие целиком — кабинет снова свободен.
- **WhatsApp:** клиенту — подтверждение со ссылкой отмены, сообщение об отмене, напоминание накануне;
  администраторам — новая запись, отмена, «ушёл со страницы, не записавшись» (имя и телефон, чтобы перезвонить).

## Как устроено

```
public/index.html ──GET /api/schedule──▶ api/schedule.js ─▶ МойКласс: занятия школы за неделю → свободные слоты
                 ──POST /api/book─────▶ api/book.js ───▶ МойКласс: ученик → запись в группу → занятие; WhatsApp
                 ──POST /api/lead─────▶ api/lead.js ───▶ WhatsApp администраторам (ничего не хранится)
WhatsApp-ссылка ──GET /cancel?t=…─────▶ api/cancel.js ─▶ страница с кнопкой (GET ничего не отменяет)
                 ──POST /api/cancel───▶ api/cancel.js ─▶ МойКласс: удалить занятие; WhatsApp
Vercel Cron 13:00 ──GET /api/cron─────▶ api/cron.js ───▶ МойКласс: пробные на завтра → напоминания
```

| Файл | Что внутри |
|---|---|
| `public/index.html`, `public/logo.png` | страница записи (единственное, что публично) |
| `api/*.js` | функции Vercel: разобрать запрос → вызвать `lib` → ответить |
| `lib/config.js` | переменные окружения и их проверка (локально — ещё файл `.env`) |
| `lib/moyklass.js` | клиент API МойКласс: токен, запросы, постраничная загрузка, повтор при 429, кэш справочников 10 мин |
| `lib/time.js` | дата и время Алматы (UTC+5), сетка стартов, пересечение интервалов |
| `lib/availability.js` | расчёт свободного времени — чистые функции, без сети |
| `lib/booking.js` | запись, отмена, напоминания, проверки и правила |
| `lib/notify.js` | WhatsApp (GREEN-API) и тексты всех сообщений |
| `lib/sign.js` | подпись ссылок отмены (HMAC) |
| `lib/http.js`, `lib/cancel-page.js` | ответы, чтение запроса, ответ об ошибке; HTML страницы отмены |
| `tools/list.js`, `tools/check.js` | справочники МойКласс; диагностика по номеру телефона |
| `tests/` | тесты: `npm test` |

Защита от одновременной записи: перед созданием занятия кабинет проверяется заново, а после — если в нём
появилось другое пересекающееся занятие, созданное раньше, своё удаляется и человек видит «Это время только что заняли».

## Настройки

Все переменные с подробными комментариями и примерами — в [.env.example](.env.example).

| Переменная | Обязательна | По умолчанию | Что это |
|---|---|---|---|
| `MOYKLASS_API_KEY` | да | — | ключ API МойКласс |
| `SIGNING_SECRET` | да | — | секрет подписи ссылок отмены (длинная случайная строка; не менять) |
| `MOYKLASS_TRIAL_GROUPS` | да | — | инструменты и кабинеты: `группа:кабинет,кабинет;группа`, напр. `163997:33466;164076:33469,33467;230182` |
| `MOYKLASS_JOIN_STATUS_ID` | | статус со словом «Проб» | статус записи в группу (у школы — `41075` «Записан») |
| `MOYKLASS_SOURCE_ID` | | — | источник «откуда узнали» для новых учеников |
| `MOYKLASS_SOURCE_ID_IG` | | `MOYKLASS_SOURCE_ID` | источник для пришедших из Instagram-бота (`?ig=`) |
| `WORK_START`, `WORK_END` | | `10:00`, `22:00` | рабочий день |
| `TRIAL_MINUTES` | | `45` | длительность пробного урока, мин |
| `SLOT_STEP_MINUTES` | | `15` | шаг стартов, мин |
| `BOOKING_DAYS` | | `7` | сколько дней показывать |
| `SEARCH_WEEKS` | | `8` | на сколько недель вперёд искать свободное время |
| `BOOKING_CUTOFF_HOURS` | | `3` | за сколько часов до урока закрываются запись и отмена |
| `GREEN_URL`, `GREEN_ID`, `GREEN_TOKEN` | | — | GREEN-API; не заданы — WhatsApp не отправляется |
| `ADMIN_WHATSAPP` | | — | номера администраторов или `…@g.us` через запятую |
| `PUBLIC_URL` | | домен запроса | адрес сайта для ссылок отмены |
| `CRON_SECRET` | | — | секрет `/api/cron`; не задан — напоминания выключены |
| `REMINDER_MODE` | | `daily` | `daily` — все пробные на завтра; `hourly` — за 24–25 ч |
| `MOYKLASS_API_URL` | | `https://api.moyklass.com` | только для тестов |

### Как узнать ID

```bash
cp .env.example .env      # вписать MOYKLASS_API_KEY
node tools/list.js        # группы, филиалы, кабинеты, статусы записи, источники
```

Сайт работает с единственным активным филиалом МойКласс; если их станет несколько — ошибка `config`.

## Деплой на Vercel

1. Проект подключён к GitHub: каждый push в `main` = новый деплой.
2. Project Settings → Environment Variables: задать переменные из таблицы (минимум три обязательные,
   плюс `GREEN_*`, `ADMIN_WHATSAPP`, `CRON_SECRET`).
3. После изменения переменных: Deployments → последний → Redeploy.
4. Проверить: открыть сайт, `https://<сайт>/api/schedule` должен вернуть JSON с `days`.

Настройки Vercel — в `vercel.json`: публичная папка `public/`, регион `fra1` (Франкфурт),
`/cancel` → `/api/cancel`, cron `0 8 * * *` (13:00 Алматы). `.vercelignore` не пускает в деплой `.env`, `tools/`, `tests/`.

## Диагностика

- **Что с учеником:** `node tools/check.js +77011234567` — ученик, записи в группы со статусами,
  записи на занятия (дата, время, группа, кабинет, test), задачи.
- **Логи:** Vercel → проект → Logs (ошибки МойКласс и WhatsApp пишутся туда).
- **Ответы API при ошибке** (секреты в них не попадают):
  - `{"error":"config","missing":[…],"problems":[…]}` — не задана переменная или ошибка в `MOYKLASS_TRIAL_GROUPS`
    (неизвестная группа, архивный кабинет, несколько филиалов);
  - `{"error":"crm-auth"}` — МойКласс не принял `MOYKLASS_API_KEY`;
  - `{"error":"crm","status":…,"detail":"…"}` — МойКласс ответил ошибкой (какой запрос и код);
    `429` — превышен лимит запросов МойКласс (клиент уже повторил дважды);
  - `{"error":"server"}` — прочее, подробности в логах.
- **Ответы записи:** `taken` — время заняли, `used` — у номера уже есть пробный, `already` — уже записан
  на это же время, `late` — меньше 3 ч до урока, `gone` — запись не найдена (отмена), `bad` — неверные данные.

## Тесты

```bash
npm test
```

Без сети и без настоящего `.env`: МойКласс и GREEN-API подменяются мок-сервером на локальном порту (`tests/mock.js`),
функции `api/*` вызываются напрямую. Юнит-тесты — расчёт свободного времени и время Алматы.

## Ограничения

- **Cron раз в день.** На тарифе Hobby Vercel запускает cron не чаще раза в сутки, поэтому напоминания —
  в 13:00 обо всех пробных уроках завтра. Для напоминаний ровно за сутки: `REMINDER_MODE=hourly` и внешний
  планировщик (например, cron-job.org), вызывающий `https://<сайт>/api/cron?key=<CRON_SECRET>` каждый час.
- **Серверы вне Казахстана.** Функции работают во Франкфурте (`fra1`); у Vercel нет региона в Казахстане.
  Домен `.kz` можно подключить к Vercel, но хостинг будет зарубежным — учитывайте требования к хранению
  персональных данных (сами данные хранятся в МойКласс, сайт их не сохраняет).
- **Лимит запросов МойКласс.** При всплеске посещений API может отвечать 429; расписание кэшируется на 30 с,
  справочники — на 10 мин.
- Защиты от спама — только скрытое поле-ловушка; без хранилища ограничить частоту запросов нельзя.
